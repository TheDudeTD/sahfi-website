# SAHFI — Official Website & EPK

Single-page website and Electronic Press Kit for **SAHFI**, a DJ and producer from Sarajevo. Built with React, React Router (static prerender), Vite, and Tailwind CSS, and hosted on Cloudflare Pages.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # EPK PDF + static site → build/client
npm run check    # typecheck + content validation
```

- **[EDITING.md](EDITING.md):** how to update tracks, videos, bio, photos, and socials (for the artist)
- **[DEPLOY.md](DEPLOY.md):** Cloudflare Pages + custom domain setup
- **[CONTEXT.md](CONTEXT.md):** architecture, folder map, how to add or swap sections
